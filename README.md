# Loan-Eligibility-Prediction-Classification
# Loan Approval Prediction using Machine Learning

### Ananya Sharma

A Machine Learning project that predicts whether a loan application is likely to be approved based on applicant information.

---

## 📌 Project Overview

This project develops a Machine Learning classification model to predict loan approval outcomes based on applicant details.

The project covers the complete Machine Learning workflow, including data cleaning, exploratory data analysis, feature engineering, preprocessing, model comparison, cross-validation, hyperparameter tuning, and model evaluation.

---

## 🎯 Problem Statement

Financial institutions receive a large number of loan applications. Evaluating applications efficiently can help improve the decision-making process.

The objective of this project is to build a classification model that predicts whether a loan application will be **approved or rejected** based on available applicant information.
